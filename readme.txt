Disable right-click on your website and show a short, customizable notification instead.

== Description ==

Right Click Disable blocks the right-click menu on the front end of your site and shows a temporary, centered notification.

**Features**

* ON/OFF setting under Settings > Right Click Disable
* Customizable message (default: "Right click is disabled!")
* 5 designs: Dark, Light, Green, Red and Blue
* Responsive and compatible with modern themes and Elementor
* Assets load only when the feature is ON
* No external libraries

**Please note:** this only discourages casual copying. It cannot fully protect your content, because visitors can still use browser menus, keyboard shortcuts, view-source or developer tools.

== Installation ==

1. Upload the `right-click-disable` folder to `/wp-content/plugins/`, or install the ZIP via Plugins > Add New Plugin > Upload Plugin.
2. Activate the plugin through the Plugins screen.
3. Go to Settings > Right Click Disable, set the toggle to ON, and save.

== Frequently Asked Questions ==

= How do I restore normal right-click? =

Set the toggle to OFF under Settings > Right Click Disable and save.

= Does this fully protect my images and text? =

No. It only blocks the right-click menu. Determined visitors can still copy content in other ways.

= Is right-click blocked in Elementor's editor? =

No. The plugin skips Elementor preview mode and the Customizer preview so you can keep editing.
